# 4CO4CO
OTT 통합검색 플랫폼인 '모아봄'을 개발하기 위해 4명의 협업자들이 모인 4CO4CO팀입니다.

## 팀원
- 오원석 - 팀장(front,back)
- 국다인 - front,back
- 이승민 - front,back
- 남기윤 - front,back

## 업무 분장
### 개발분야 업무 분장

오원석: 프로젝트 환경 세팅/메인, 추천 페이지 개발/S3연동 및 서버 배포

국다인: 상세, 마이페이지 개발

이승민: 로그인, 회원가입 개발/프론트 axios API 세팅/ 회원정보 변경 기능 개발

남기윤: 검색, 인물 상세 페이지 개발/ DB 호스팅 및 데이터 세팅


### 비 개발분야 업무 분장
공통: 시나리오 작성, ERD 설계, RestFul API 명세서 작성

오원석: 일정관리표, JIRA 협업툴 회의록 관리

국다인: 요구사항 명세서 작성

이승민: 유스케이스 다이어그램 제작

남기윤: DB 크롤링 방식 구축

## Pain Point
* OTT 종류가 많고, OTT별로 컨텐츠도 다 다름
* 장르별, 카테고리별 등 자세한 검색이 어려움
* 나에게 맞는 OTT를 찾기 어려움

## Solution
* 다양한 컨텐츠와 OTT 를 한곳에서 모아봄
* 필터링 검색으로 원하는 컨텐츠만 모아봄
* OTT 추천을 통해 나에게 맞는 OTT를 모아봄
